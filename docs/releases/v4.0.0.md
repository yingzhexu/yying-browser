# YYING浏览器 4.0.0 / YYING Browser 4.0.0

## 中文版本介绍

YYING浏览器是一款基于 Electron 的桌面多账号浏览器。通过最多 10 个持久化浏览器配置，在同一台电脑上分别保存不同账号的 Cookie、网站存储和浏览记录，并通过侧栏、快捷键和批量操作提高切换效率。

这是本项目首次公开提供源码与 Windows、macOS 安装包的版本。本次直接分发作者提供的现成安装包，保留原始文件名及内容。`4.0.0` 延续原应用的版本号，项目名称由「yingying浏览器」改为「YYING浏览器」，继续使用原有数据目录。

### 下载哪个文件

| 文件 | 适用设备 |
| --- | --- |
| `YYING浏览器-4.0.0-安装版.exe` | Windows 10 / 11，64 位 Intel 或 AMD 电脑 |
| `YYING浏览器-4.0.0-Mac.dmg` | macOS 13 Ventura 及以上；同时包含 Apple 芯片和 Intel 架构 |
| `SHA256SUMS.txt` | 两个安装包的 SHA-256 校验值 |

请在本页下方 **Assets** 中下载 `.exe` 或 `.dmg`。GitHub 自动生成的 **Source code** 压缩包是源码，需要开发环境，不能直接安装。

### 本版本提供的功能

- 最多管理 10 个浏览器配置，各自保存 Cookie、LocalStorage、IndexedDB、缓存、历史记录和书签。
- 名称、备注、颜色、启动页、拖动排序及批量改名，支持按编号显示头像。
- 右侧快速切换栏、浏览器切换菜单和键盘快捷键；切换时对齐窗口位置和大小。
- 在多个配置中批量打开最多 20 个网址或搜索词，支持新标签页、替换当前页及打开后平铺窗口。
- 标签页拖动、静音、恢复已关闭标签页、地址栏联想、书签、历史、下载、页内查找、缩放、打印和视频全屏。
- 10 套主题、每个配置单独设置主题或新标签页壁纸。
- 每 15 秒保存标签页，每 30 秒刷新 Cookie 存储；退出、关机及睡眠时尝试及时保存。
- 标签页自动休眠、低性能模式、网页无响应处理及 GPU 崩溃后的下次启动回退。
- MIT 开源协议；详细中文与英文 README；作者提供的 Windows、macOS 现成安装包及 SHA-256 校验值。

### 安装与升级

- **Windows**：运行 `.exe`，按向导安装，可选择安装路径。安装向导和应用界面目前以简体中文为主。
- **macOS**：打开 `.dmg`，将「YYING浏览器」拖入「应用程序」。该构建采用本机临时签名，没有 Apple Developer ID 签名或公证，首次打开可能需要在系统「隐私与安全性」中确认。
- **升级**：先正常退出旧版，再安装新版。应用继续使用 `yingying浏览器` 数据目录；覆盖安装不主动清空配置。升级前可在完全退出应用后备份该目录。

Windows 安装包没有发布者数字签名，系统可能显示未知发布者提示。安装与首次启动的具体提示取决于系统设置；本页提供源码和校验值供核对。

### 当前范围

本版本提供中文应用界面、中文和英文项目文档与发行说明，未提供完整英文应用界面切换。配置隔离针对本地浏览状态，所有配置默认仍使用电脑的网络连接。网站可自行使登录失效；定期保存不能保证突然断电时所有最新状态均已写入。下载任务列表按配置分组，在当前运行期间维护，实际文件保存在系统下载文件夹。

## English release notes

YYING Browser is an Electron desktop browser for managing multiple accounts on one computer. Up to 10 persistent profiles keep cookies, website storage and browsing records separate, with a profile sidebar, keyboard shortcuts and batch actions for daily use.

This is the project's first public release with source code and Windows/macOS installers. The author's existing installers are uploaded with their original filenames and contents. The existing application version, `4.0.0`, is retained. The application is now named YYING Browser while continuing to use the original `yingying浏览器` data directory.

### Choose a download

| File | Platform |
| --- | --- |
| `YYING浏览器-4.0.0-安装版.exe` | Windows 10 / 11 on 64-bit Intel or AMD PCs |
| `YYING浏览器-4.0.0-Mac.dmg` | macOS 13 Ventura or later; includes both Apple Silicon and Intel binaries |
| `SHA256SUMS.txt` | SHA-256 checksums for both installers |

Download the `.exe` or `.dmg` from **Assets** below. GitHub's automatically generated **Source code** archives contain development files, not ready-to-install applications.

### Included in this release

- Up to 10 persistent profiles with separate cookies, LocalStorage, IndexedDB, cache, history and bookmarks.
- Profile names, notes, colors, startup URLs, drag-to-reorder and numbered batch renaming.
- Profile sidebar, switcher menu and keyboard shortcuts, with window position and size aligned when switching.
- Open up to 20 URLs or search terms across selected profiles, using new tabs or the current tab, with optional window tiling.
- Tab reordering, muting, reopening closed tabs, address suggestions, bookmarks, history, downloads, find, zoom, print and video fullscreen.
- Ten themes, per-profile appearance and custom new-tab wallpapers.
- Tab saving every 15 seconds and cookie flushing every 30 seconds, plus save attempts on quit, shutdown and sleep.
- Idle-tab sleeping, low-performance mode, unresponsive-page handling and next-launch GPU fallback after repeated crashes.
- MIT-licensed source, detailed Chinese and English documentation, and the author-provided Windows/macOS installers with SHA-256 checksums.

### Install and update

- **Windows:** run the `.exe` installer and follow the wizard. The installer and application interface are currently primarily Simplified Chinese.
- **macOS:** open the `.dmg` and drag YYING浏览器 into Applications. This build is ad-hoc signed, without Apple Developer ID signing or notarization. First launch may require confirmation in the system's Privacy & Security settings.
- **Updates:** quit the old application before installing the new version. The original data directory is reused and is not intentionally erased during an ordinary upgrade. Back it up while the application is fully closed if you need a restorable copy.

The Windows installer has no publisher code-signing certificate and may show an unknown-publisher notice. Exact installation and first-launch prompts depend on the operating system. Source code and checksums are available for inspection.

### Current scope

English project documentation and release notes are included; a full English application interface is not implemented. Profile separation applies to local browsing state; profiles use the computer's network connection by default. Websites can expire or revoke sessions, and periodic saving does not guarantee that every recent change survives unexpected power loss. Download lists are grouped by profile for the current application session; downloaded files are stored in the system Downloads directory.
